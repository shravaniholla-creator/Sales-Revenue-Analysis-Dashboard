# Sales & Revenue Analysis Dashboard

## 📌 Project Overview

This project is a Sales & Revenue Analysis Dashboard developed using Python, Pandas, and Microsoft Excel.

The project analyzes sales data and presents important business insights through an interactive Excel dashboard.

## 🎯 Objectives

- Analyze sales and revenue data
- Identify top-performing products
- Analyze monthly revenue trends
- Compare revenue across categories
- Compare revenue across regions
- Present insights using charts and KPIs

## 🛠️ Technologies Used

- Python
- Pandas
- Microsoft Excel
- OpenPyXL
- GitHub

## 📊 Dashboard Features

- Total Revenue
- Total Orders
- Total Units Sold
- Monthly Revenue Trend
- Top Performing Products
- Revenue by Category
- Revenue by Region

## 📁 Project Files

| File | Description |
|---|---|
| `create_dataset.py` | Generates the sales dataset |
| `sales_data.csv` | Sales data used for analysis |
| `analyze_sales.py` | Performs data analysis using Pandas |
| `Sales_Revenue_Dashboard.xlsx` | Final Excel dashboard |
